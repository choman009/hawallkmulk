# ڕێنمایی دەستپێکردنی Hawall mulk

## بینینی سیستەمەکە

لە تێرمیناڵی فۆڵدەری پرۆژەکە ئەمانە جێبەجێ بکە:

```powershell
npm ci
npm run dev
```

بەستەر: http://127.0.0.1:3000

تا Supabase پەیوەست نەکرێت، سیستەمەکە **وەشانی تاقیکردنەوەیە**. زانیارییەکان خەیاڵین و تەنها لە وێبگەڕەکەت پاشەکەوت دەکرێن؛ زانیاریی ڕاستەقینەی کڕیارانی تێدا مەنووسە. بە «پێشبینین وەک» دەتوانیت جیاوازیی ڕووکار و بینینی خاوەن، کارمەند و فریلانسر ببینیت.

## پەیوەستکردنی Supabase

١. پرۆژەیەکی نوێ لە Supabase دروست بکە.

٢. ناوەڕۆکی تەواوی ئەم فایلە لە SQL Editor جێبەجێ بکە:

`supabase/migrations/202610300001_initial.sql`

`supabase/migrations/202610310001_secondary_phones.sql`

فایلەکان بە ڕیز جێبەجێ بکە. ئەگەر پرۆژەکەت پێشتر دامەزراوە، تەنها فایلە نوێیەکەی `202610310001_secondary_phones.sql` جێبەجێ بکە؛ فایلە سەرەتاییەکە دووبارە مەکەرەوە. ئەمە خانەی ئارەزوومەندانەی ژمارەی مۆبایلی دووەم بۆ موڵک و نووسینگە هاوکارەکان زیاد دەکات و تۆمارەکان دەپارێزێت.

ئەمە خشتەکان، یاساکانی دەسەڵات و شوێنی تایبەتی وێنەکان دروست دەکات. تەنها جارێک لە پرۆژەی نوێ جێبەجێی بکە.

٣. لە Authentication، خۆتۆمارکردنی گشتی داخە. لە Users هەژماری خۆت دروست بکە، پاشان لە SQL Editor ئەمە جێبەجێ بکە؛ ناو و ئیمەیڵە نموونەییەکان بە هی خۆت بگۆڕە:

```sql
update public.profiles
set role = 'owner', active = true, name = 'ناوی خۆت'
where id = (select id from auth.users where email = 'you@example.com');
```

٤. کۆپیی `.env.example` بە ناوی `.env.local` دروست بکە. URL و publishable key ـی پرۆژەکەت و service-role key ـی سێرڤەر لێرە دابنێ. ئەو کلیلی service-role ـە بڵاو مەکەرەوە و مەیخەرە ناو گیت؛ هیچ ناوێکی بە `NEXT_PUBLIC_` دەستپێکردوو بۆی بەکارمەهێنە.

٥. `NEXT_PUBLIC_SITE_URL` لە ناوخۆدا بکە بە `http://127.0.0.1:3000`؛ لە کاتی بڵاوکردنەوە بکە بە دۆمەینی HTTPS ـی ڕاستەقینە. سێرڤەرەکە دووبارە هەڵبکەوە.

٦. لە ڕێکخستنی Authentication، Site URL و Redirect URLs دیاری بکە. قالبی ئیمەیڵی بانگهێشت و گەڕاندنەوەی وشەی نهێنی دەبێت بەستەری token-hash بەکاربهێنن. نموونەی تەواو لە `README.md` هەیە؛ ئەم هەنگاوە پێویستە بۆ کارکردنی بانگهێشت.

٧. بە هەژماری خاوەن بچۆ ژوورەوە، زانیاریی نووسینگەکە نوێ بکەرەوە و لە «تیم و دەسەڵاتەکان» ئەندامەکان بانگهێشت بکە. ئەندامەکە بە ئیمەیڵ وشەی نهێنیی خۆی دیاری دەکات.

## کاری ڕۆژانە

- **موڵک:** موڵکەکە زیاد بکە و هێنەرەکەی دیاری بکە؛ هێنەر جیاوازە لە کەسی تۆمارکەر.
- **داواکاری:** جۆری موڵک، شوێن و بودجەی کڕیار تۆمار بکە؛ لە وردەکارییەکەدا موڵکە گونجاوەکان دەردەکەون. دراوی جیاواز بە خۆکار ناگۆڕدرێت.
- **سپاردنی ئەرک:** لە هەمان تۆمارەوە فریلانسر دیاری بکە. فریلانسر ئەو تۆمارە دەبینێت و ئەنجامی کار دەنووسێت؛ نرخی تۆماری کەسێکی تر ناگۆڕێت.
- **پەیوەندی:** دوگمەی تەلەفون یان واتسئەپ بکە. سیستەمەکە پەیامێک بە خۆکار نانێرێت.
- **هەڵوەشاندنەوە:** تەواوکردنی ئەرک، دەستگەیشتن بۆ پشکنینی کارەکە دەپارێزێت. هەڵوەشاندنەوەی ئەرک دەستگەیشتنی پەیوەست بە ئەرکەکە لادەبات؛ تۆماری هی خۆی هەر دەبینێت.
- **ئەرشیف:** تەنها خاوەن و ئەدمین تۆمار ئەرشیف دەکەن؛ مێژووی کارەکە دەمێنێتەوە.

## بڵاوکردنەوە لە Vercel

پرۆژەکە بخەرە ڕیپۆزیتۆرییەکی تایبەت، پاشان لە Vercel هاوردەی بکە بە Next.js. هەمان environment variable ـەکان زیاد بکە و URL ـەکان بگۆڕە بۆ دۆمەینی کۆتایی. لە Supabase ـیش Site URL و Redirect URLs نوێ بکەرەوە.

پێش بەکارهێنانی ڕاستەقینە، بە هەژماری جیاوازی خاوەن و فریلانسر بانگهێشت، چوونەژوورەوە، سپاردن، هەڵوەشاندنەوە، وێنەکان و گەڕاندنەوەی وشەی نهێنی تاقی بکەرەوە. ئەم کارانە هێشتا لە پرۆژەی Supabase ـی ئێوە تاقی نەکراونەتەوە.

## نوێکردنەوە: سڕینەوە بۆ خاوەن و ئەدمین

لە SQL Editorی هەمان پرۆژەی Supabaseی وێبسایتەکە، فایلەکانی خوارەوە بە ڕیز جێبەجێ بکە:

١. `supabase/migrations/202610310001_secondary_phones.sql` — بۆ ژمارەی مۆبایلی دووەم، ئەگەر پێشتر سەرکەوتوو نەبووە.

٢. `supabase/migrations/202610310002_record_deletion.sql` — بۆ سڕینەوە و پاراستنی دەسەڵاتەکان.

ئەم دوو فایلە نوێیە دەتوانرێت دووبارە جێبەجێ بکرێن. فایلە سەرەتاییەکە دووبارە مەکەرەوە.

سڕینەوە لە پەنجەرەی وردەکاریی موڵک، داواکاری و نووسینگە، و لە کارتی ئەرکەکان بەردەستە؛ تەنها بۆ خاوەن و ئەدمینی چالاک کە مۆڵەتی نووسینیان هەیە. پێش سڕینەوە پەنجەرەی پشتڕاستکردنەوە پیشان دەدرێت. تۆمار و ئەرکە پەیوەستەکان لە دەسترس دەردەچن؛ سڕینەوەی نووسینگە موڵک و داواکارییەکانی نابات. داتای سەرەکی لە داتابەیس دەمێنێت بۆ گەڕاندنەوە بە دەستی بەڕێوەبەری داتابەیس.
